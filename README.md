# Inovation-Flow
Repositório oficial do projeto campeão do programa Rock Skills (FIAP). Trata-se de um sistema de automação e personalização de atendimento via WhatsApp para o setor educacional (Graduação, Pós e MBA), utilizando a inteligência estratégica do Google Gemini para ajustar o tom de voz e otimizar a conversão de candidatos.
